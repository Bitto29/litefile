Add documents to LiteFile

You only need to edit documents.js. No database or dashboard is involved.

  1. Open documents.js in your GitHub repository.
  2. Copy the sample below and paste it after the existing document object.
  3. Change its title, folder, and embedUrl. From Scribd's iframe code, copy only the URL inside src="...".
  4. Give it a unique id, then commit the change.
{ id: "chemistry-1st-paper", title: "Chemistry 1st Paper", folder: "Chemistry", description: "Class notes and practice material.", embedUrl: "https://www.scribd.com/embeds/DOCUMENT_ID/content", sourceUrl: "https://www.scribd.com/document/DOCUMENT_ID", author: "Basit Iqbal Bitto" }

Documents with the same folder name automatically appear together. You can create as many folders as you need.
